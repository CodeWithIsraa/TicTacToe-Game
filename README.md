# 🎮 Tic-Tac-Toe Console Game (C++)

A classic Tic-Tac-Toe game built with modern C++ using Object-Oriented Programming (OOP) concepts.

## ✨ Features
- 👥 **2 Players Mode:** Play locally with a friend.
- 🤖 **Player vs Smart AI:** Play against a bot that blocks moves and aims to win.
- 📊 **Live Scoreboard:** Tracks wins, losses, and draws across multiple rounds.
- 🛡️ **Input Validation:** Handles invalid numbers, letters, and occupied cells without crashing.
- 🖥️ **Clean UI:** Auto-clears the console for a smooth gaming experience.

## 🚀 How to Run
1. Open the project in any C++ environment (VS Code, Code::Blocks, or OnlineGDB).
2. Compile and run `main.cpp`.
3. Enjoy the game!
